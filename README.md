### 🥇 [AWS Enterprise Platform Engineering Capstone](https://github.com/Ashish420-tech/aws-enterprise-capstone)
> *Full-scale, production-grade AWS DevOps platform built to enterprise engineering standards*

Architected and delivered a complete AWS platform that simulates how senior platform engineering teams design, secure, and automate cloud-native infrastructure. Every decision reflects real enterprise production requirements — from modular IaC and passwordless CI/CD to hardened Kubernetes runtimes and audit-grade observability.

**Key engineering highlights:**
- **7-module Terraform architecture** covering VPC, EC2, EKS, ECR, IAM, Security Groups, and GitHub OIDC — with remote state backend using S3 versioning and DynamoDB locking
- **Passwordless CI/CD** via GitHub OIDC federation — zero static AWS credentials across all pipelines; eliminates the #1 cause of cloud credential breaches
- **Production EKS cluster** with managed node groups, Helm-packaged deployments, and rollback-capable releases
- **12 active security controls** — Trivy image + IaC scanning, SSM-only EC2, non-root containers, read-only filesystem, CloudTrail, IAM Access Analyzer, VPC Flow Logs, Secrets Manager
- **Ansible over SSM** for EC2 configuration management — no SSH exposure at any layer
- **CloudWatch Container Insights + Fluent Bit + SNS alerting** for full operational observability
